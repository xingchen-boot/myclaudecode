# 指令选择和文件引用功能设计文档

## 一、功能概述

在现有的 AI 终端应用中添加两个核心功能：
1. **指令选择功能**：通过 `/` 触发指令列表，支持上下选择和 Tab 确认
2. **文件引用功能**：通过 `@` 触发文件列表，选择文件后将内容作为上下文发送给 AI

## 二、操作动线设计

### 2.1 指令选择功能 (`/`)

**触发条件**：
- 用户在输入框中输入 `/`
- `/` 前后没有空格（即 `/` 是独立的指令前缀）

**操作流程**：
1. 用户输入 `/` 后，自动弹出指令列表
2. 列表显示所有可用指令，初始显示全部
3. 用户可以通过以下方式操作：
   - **上下箭头键**：移动选择光标
   - **Tab 键**：确认选择当前高亮的指令
   - **继续输入**：随着输入字符，实时筛选匹配的指令
   - **Enter 键**：确认选择
   - **Esc 键**：取消选择，关闭列表

**指令列表内容**：
- `/help` - 显示帮助信息
- `/clear` - 清空对话历史
- `/history` - 查看对话历史
- `/exit` 或 `/quit` - 退出程序
- `/model` - 切换模型
- `/config` - 查看配置信息

**UI 展示**：
```
请输入：/
┌─────────────────────────────────────┐
│ 可用指令：                          │
│ > /help    - 显示帮助信息            │
│   /clear   - 清空对话历史            │
│   /history - 查看对话历史            │
│   /exit    - 退出程序                │
│   /model   - 切换模型               │
│   /config  - 查看配置信息            │
└─────────────────────────────────────┘
```

### 2.2 文件引用功能 (`@`)

**触发条件**：
- 用户在输入框中输入 `@`
- `@` 前后没有空格（即 `@` 是独立的引用前缀）

**操作流程**：
1. 用户输入 `@` 后，自动弹出文件列表
2. 列表显示当前项目目录下的所有文件
3. 用户可以通过以下方式操作：
   - **上下箭头键**：移动选择光标
   - **Tab 键**：确认选择当前高亮的文件
   - **继续输入**：随着输入字符，实时筛选匹配的文件
   - **Enter 键**：确认选择
   - **Esc 键**：取消选择，关闭列表

**文件列表内容**：
- 显示当前项目目录下的所有文件
- 按文件类型分组显示
- 支持目录结构展示

**UI 展示**：
```
请输入：@
┌─────────────────────────────────────┐
│ 项目文件：                          │
│ > src/app.js                        │
│   src/utils/logger.js               │
│   src/utils/init.js                 │
│   src/utils/fsHandle.js             │
│   src/utils/pathUtils.js            │
│   package.json                      │
│   CHANGELOG.md                      │
└─────────────────────────────────────┘
```

### 2.3 选中后的处理

**指令选择后**：
1. 用户通过 Tab 或 Enter 确认选择指令
2. **列表立即消失**，选中的指令填入输入框
3. 输入框显示选中的指令（如 `/help`）
4. 用户可以继续编辑指令内容（如添加参数）
5. **用户按下 Enter 确认发送后**，才解析并执行指令

**执行流程**：
```
用户选择指令 → 列表消失 → 指令填入输入框 → 用户确认发送 → 解析指令 → 执行指令
```

**文件引用后**：
- 将选中的文件路径填入输入框，格式为 `@文件路径`
- 在发送给 AI 时，自动读取文件内容并作为上下文
- 消息格式示例：
  ```
  用户消息：@src/app.js 这个文件的作用是什么？
  发送给 AI：
  - 用户问题：这个文件的作用是什么？
  - 引用文件内容：[文件内容]
  ```

## 三、交互细节

### 3.1 列表展示规则
- 列表最多显示 10 个项目
- 如果超过 10 个，显示滚动提示
- 选中项高亮显示
- 支持实时筛选

### 3.2 键盘操作
- **↑/↓**：移动选择
- **Tab**：确认选择（列表消失，内容填入输入框）
- **Enter**：确认选择并发送（列表消失，内容填入输入框后立即发送）
- **Esc**：取消选择，关闭列表
- **Backspace**：删除输入字符，触发重新筛选

### 3.3 边界情况处理
- 如果没有匹配的指令/文件，显示"无匹配项"
- 如果指令/文件列表为空，显示"暂无可用项"
- 输入框为空时，显示全部指令/文件

## 四、指令解析与执行

### 4.1 指令解析时机
- 只有当用户在输入框中按下 Enter 确认发送后，才解析指令
- 指令解析发生在消息发送给 AI 之前

### 4.2 指令执行流程
```
用户输入（包含指令）
    ↓
按下 Enter 确认发送
    ↓
检测是否以 / 开头
    ↓
是 → 解析指令 → 执行指令 → 返回结果
    ↓
否 → 作为普通消息发送给 AI
```

### 4.3 指令与消息的混合处理
- 如果用户输入中包含指令（如 `/help`），则执行指令
- 如果用户输入中包含文件引用（如 `@src/app.js`），则读取文件内容作为上下文
- 如果同时包含指令和文件引用，先执行指令，再处理文件引用
